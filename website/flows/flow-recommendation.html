What This Flow Does

When a user asks for recommendations, the system first fetches their profile and the full list of available opportunities. It does not just throw everything at the user. Instead, it first filters out opportunities that the user clearly cannot apply for based on basic rules.

After the initial filter, an AI ranking model steps in. This model looks at the user's skills, background, and preferences and compares them against each remaining opportunity. It assigns a relevance score to each one, ranking them from most likely to be a great fit to least likely.

To make the suggestions feel personal and helpful, the system also asks a language model to write a short explanation for each recommendation. These explanations tell the user why a particular opportunity was suggested, mentioning matching skills or profile details.

The user sees a short list of the top recommendations, each with its own score and plain-English explanation. This saves the user time searching through hundreds of options and helps them discover opportunities they might have otherwise missed.
