What This Flow Does

This flow works like a helpful reminder service for the whole platform. A background scheduler regularly checks the database for upcoming deadlines, such as application closing dates or document submission due dates. It looks specifically at deadlines that are coming up in the next few days.

For each upcoming deadline, the system creates a notification and puts it into a message queue. The queue acts like a to-do list that multiple workers can pick from. Different workers handle different channels: one sends emails, another sends push notifications to mobile devices, and another sends WhatsApp messages using pre-approved templates.

When a notification is successfully sent, the system updates its records so it knows not to send the same reminder again. Users can also acknowledge notifications from the app, and that status is saved too. The system tracks whether a notification was sent, delivered, or failed to send.

This flow makes sure users never miss important deadlines. It automatically reaches them through the channels they prefer and keeps a clear record of every message sent.
