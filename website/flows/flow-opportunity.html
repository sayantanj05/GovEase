What This Flow Does

Admins use this flow to create and publish new opportunities on the platform. They enter details like the title, eligibility rules, deadlines, and any documents needed. The system checks that all the rules are written correctly before saving. Once saved, the opportunity is indexed so it can be found quickly when users search.

When a regular user searches for opportunities, the system looks at what they asked for and checks its database. Before searching the main database every single time, the system checks a fast temporary cache. If the same search was done recently, the results are already there and can be shown instantly. If not, the system fetches fresh results from the database and stores a copy in the cache for next time.

This means searches feel fast even when many people are using the platform. The cache has a time limit, so old results are automatically replaced with new ones. Users see the most current opportunities while the system saves processing power by not repeating the same searches over and over.
