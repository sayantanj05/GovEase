What This Flow Does

This flow connects the platform to outside systems and services. It allows the system to pull in opportunities and schemes from external government portals and APIs. The integration service fetches this data using secure API keys, then cleans and reshapes it so it fits neatly into the platform's own database.

Users also benefit from this flow when they apply for something through an external portal. Instead of forcing the user to stay inside the app, the system lets them complete their application on an outside website. Once they submit it there, the external system sends a status update back to the platform.

The integration service receives that status update and compares it with what is stored locally. If the status has changed, it updates the local database to match. The user is then notified of the change so they always have the latest information without having to check multiple websites.

This flow breaks down walls between the platform and the outside world. Users get more opportunities to choose from, and admins get a single dashboard that shows the status of both internal and external applications.
