What This Flow Does

When a user needs to upload a document, they simply select the file from their device. The system does not make the file travel through the main backend servers. Instead, it creates a special, time-limited upload link that sends the file straight to secure cloud storage. This makes uploading fast and keeps the file safe while it travels.

After the file is uploaded, it is not immediately trusted. The system puts the document into a virus-scanning queue. A separate scanning service checks the file for malware and harmful content. Only after the scan comes back clean does the system save the document's details in the database.

When the user wants to download or view their document later, the system first checks that they are allowed to access it. If they are, it creates another short-lived link that lets them download the file directly from secure storage. These links expire quickly for security.

This flow makes document handling fast, secure, and user-friendly. Files never sit exposed on backend servers, everything is scanned for safety, and users can access their documents whenever they need them.
