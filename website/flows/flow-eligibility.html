What This Flow Does

When a user wants to know if they qualify for a specific opportunity, the system asks a simple question: does this person meet the rules? To answer that, it pulls the user's profile details and the opportunity's requirements. It looks at things like age, education, income, category, and work experience.

The system then runs a set of clear, rule-based checks. For example, it might check whether the user is old enough, has the right degree, or earns less than a certain amount. These checks are deterministic, meaning they always give the same result for the same inputs. There is no guessing involved.

For every rule that is checked, the system writes down a simple explanation. If the user qualifies, it says why. If the user does not qualify, it points out which rule they missed. These explanations are stored in an audit log along with the user ID, opportunity ID, and the exact time the check was done.

The final result shows whether the user is eligible, a confidence score, and a plain-language explanation for each rule. This makes it easy for users to understand why they qualify or what they need to change. The audit log also helps admins review decisions and makes the system transparent and trustworthy.
