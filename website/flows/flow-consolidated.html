About This Diagram

This consolidated flow chart combines all 13 individual data flows into a single system architecture view. It is organized into six logical layers:

  • User Layer: End users and administrators who interact with the platform
  • Client Layer: The React.js frontend that serves as the single entry point
  • System Layer: Core microservices handling authentication, profiles, documents, opportunities, eligibility, recommendations, applications, notifications, admin tasks, integrations, and audit
  • Processing Layer: AI/LLM services, OCR engine, virus scanner, and notification channel workers
  • Data Layer: MongoDB, Redis cache, S3 object storage, and message queue
  • External Systems: Government APIs, external portals, and calendar services
