What This Flow Does

When a user first signs up or decides to update their details, they enter information like their name, education, work experience, skills, and category. All of this is saved in one place so the user never has to type it again. The system also collects important personal details like date of birth, gender, income, and disability status.

Before saving anything to the database, the system locks down the sensitive fields using strong encryption. That means even if someone somehow gets access to the database, they cannot read private details like income or disability status without a special key. Regular fields like skills and experience are stored normally.

The system also calculates a profile completeness score from zero to one hundred. This score tells the user how much of their profile is filled out. The more complete the profile, the better the platform can match the user with relevant opportunities. Every time the user edits their profile, any old cached data is cleared out so fresh information is always shown.

This flow makes sure user data is kept safe, stays up to date, and is ready to be used by other parts of the system like eligibility checks and recommendations.
