What This Flow Does

When a user uploads a document like a certificate or ID card, the system does not just store the file. It sends the document to a smart scanning engine that reads the text inside. This process is called OCR, or Optical Character Recognition. The engine turns the image of the document into plain text that a computer can understand.

The extracted text is then passed to an AI service that organizes the information into structured data. It figures out which parts are names, dates, numbers, or other important fields. This structured data is saved temporarily as a suggestion for the user's profile.

Before anything is permanently saved, the user gets to review the extracted information. They can confirm that it is correct or make changes. Only after the user explicitly confirms does the system update their profile with the new data. This step prevents errors from messy handwriting or bad scans from polluting the user's records.

This flow saves users from manually typing long documents into forms. It turns paper or image files into digital profile data quickly and accurately, while keeping the user in control of what finally gets saved.
